# SelfOrWorld Frontend

SelfOrWorldのフロントエンドアプリケーションです。

## 技術スタック

- **React 18** - UIライブラリ
- **TypeScript** - 型安全性
- **Vite** - 高速ビルドツール
- **Tailwind CSS** - ユーティリティファーストのCSSフレームワーク
- **React Router** - クライアントサイドルーティング

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```

## 開発

開発サーバーは http://localhost:5173/ で起動します。

## アプリケーション構造

```
src/
├── components/     # 共通コンポーネント
│   └── Layout.tsx  # レイアウトとナビゲーション
├── pages/          # ページコンポーネント
│   ├── Home.tsx           # ホームページ
│   ├── WorldTree.tsx      # 価値観の記録と鮮明化
│   ├── Compact.tsx        # 未来の圧縮体験（週間ビュー）
│   ├── Immersion.tsx      # 明日の準備（日次タイムライン）
│   └── ReLiving.tsx       # 過去の追体験と学び
├── App.tsx         # ルーティング設定
└── main.tsx        # エントリーポイント
```

## 機能

### WorldTree（大事なことを毎日思い出す）
- 価値観の記録
- ツリー構造での価値観の鮮明化
- 深層の価値観に触れるための質問

### Compact（未来をいま生きる）
- 週間時間配分の可視化
- チャート/リスト表示の切り替え
- 調和のとれた時間配分の確認

### Immersion（明日を生きる）
- 時間ごとに区切られたタイムライン
- カテゴリー別の時間配分
- 事前準備チェックリスト

### ReLiving（過去を意味づける）
- 一日の軌跡を追体験
- 感情と振り返りの記録
- 学びの蓄積と可視化

## モック実装について

現在の実装は、UI/UXの確認を目的としたモック実装です。
データは全てハードコードされており、永続化されません。

今後の開発で、バックエンドAPIとの連携や、データの永続化を実装する予定です。
