# SelfOrWorld
「私」という意識現象が存在しなければ、「世界」は存在しないし、
「世界」が存在しなければ、「私」という意識現象は存在しない。

そんな、当たり前だけど気が付きづらい実感から始めて、
「私」という意識現象や、世界の、その特性を知ることで、
私はより自由になると信じます。

そんな、自由を獲得するために、それをサポートしてくれるアプリケーションであるように、**SelfOrWorld**は努めます。

まず何よりも私のために。

# どんな私が便利だと感じるか
私は、こんな人間です。

- 自身の奥底から湧き上がる力に突き動かされず、漫然と生きていることに焦燥感を感じている。
- つい、眼の前に飛び込んでくる誘惑に惹かれ、重要なことを忘れてしまう。
- 明日のこと、もっと先のこと、それらを考えたくない。でも大事な気がしている。

# SelfOrWorldはどうやって助けてくれるか
**SelfOrWorld**は、以下のUXを私に提供してくれます。

1. 大事なことを毎日思い出す。
2. 未来をいま生きる。
3. 過去を意味づける。

これらが私の悩みを減らし、願い事を叶えることを助けてくれることを望んでいます。

## 大事なことを毎日思い出す
私にとって大事なことは、あなたにとって大事なことではないでしょう。

あなたにとって大事なことは、私にとって大事なことではないでしょう。

でも今の私にとって大事なことは、おそらく明日の私にとって大事なことでしょう。
（言い換えれば、明日の私にとって大事なことではないのであれば、それは今日の私にとっても大事ではないかもしれません。）

大事なことを、覚えておき、思い出す。

そんな体験を、**SelfOrWorld**は提供します。

### どうやって
**SelfOrWorld**は、私が最も大事にすることを、文章で記録します。

この文章は、私だけの、でも未来も過去も、全ての私の、大事なことであることが望ましいでしょう。

なので、この文章を記録するという体験は、私が自身の深くにある価値観に触れることを要求します。

このとき、**SelfOrWorld**は、私が深層の価値観に触れることを助けてくれます。

例えば、**SelfOrWorld**は、私に以下のような質問を投げかけます。

- 今日、死を迎えるとしたら、あなたはどのような状態でありたいですか？
- 今日、世界が終わるとしたら、あなたは何をして過ごしますか？

それを言い換えれば、私にとって最も大事なことが見つかる気がします。

例えば、そうして頭に浮かんできた状態を、極めて正直に、私だけの記録として、**SelfOrWorld**に投げ入れる。

次の日から、毎日、その言葉を私に思い出させてくれるようになります。

### より鮮明に
ここで注意しなければならないのは、そういった想像は、鮮やかに想像して初めて、強く惹きつけられるという点です。

曖昧な想像だけでは、私は何をすればよいのかわからない。

どう行動に繋がっていくのか、その総体が完成しない。

**SelfOrWorld**は、私の理想を鮮明化することを、分化発展的データ構造で、助けてくれます。

#### WorldTree
私の理想状態をまとめた一つの文章。
私が参照するのはいつもこの一つの文章ですが、
それをより定着させるために、より鮮明なイメージを書き加えることができます。

例えば、どのような苦難がやってきたときに、どのような態度でそれに立ち向かいたいのか。
例えば、どのような機能を仲間に提供しながら、苦難を乗り越えたいのか。
例えば、誰を想いながら、慈しみの感情に満ちていたいのか。

それらを鮮明に想像し、それを思い出せること、
それは、私が大事なことを忘れないために、有益な手段だと信じます。

## 未来をいま生きる
未来について、いくつか諦めないといけないことがあります。

例えば、時間は有限であること。
例えば、同時に複数のことを為すことはできないこと。
例えば、世界は秩序を持っていること。

それらは、未来について考えるうえで、諦めなくてはならない事実です。

プレゼントを買わずに大切な人にプレゼントを渡すことはできないし、
まとまった時間を取らずに上司を説得することは出来ないのです。

それらを、バランスよく、理にかなった順序で並べる。

その作業を通してしか、私はより大事なことを為すことができません。

大事なことを為せなかったときの後悔は、いつも準備不足です。

### どうやって
**SelfOrWorld**は、私が未来を順序よく並べること、そして未来を試しに生きることを助けてくれます。

私は、以下の2つの機能を行き来することで、よりよい未来を創ることが出来ます。

#### Compact
未来を、いまの自分としてコンパクトに感じること。

それをCompactは助けます。

初めは、来週1週間が私にとって、調和のとれたものになっているのかどうかを確認することから始めます。

以下のような様々な形態で1週間というものを眺めてみたとき、私は何を思うのか。

私が好ましくないものに時間を取られすぎていると感じるのか。

一度、1週間を一気に生きる体験をして、私の未来を"振り返って"みましょう。

#### Immersion
明日、より善く生きることが出来るように、Immersionは時間ごとに区切られた現実を眼の前に表示してくれます。

そこで、どのように動くことで調和が得られるのか、事前にメモしておきましょう。

現時点で予測できないことは諦め、しかし予測できることには準備をし、
自身が十分だと確信できるまで行いましょう。

時に不安なままでもよいでしょう。
私は行為を通して、予測不能な状態から抜け出すことが出来るのですから。

## 過去を意味づける
過去が意味を持つのは、そこから私が学び、実践に活かしたときだけです。

しかし私はたびたび、過去に、無意味に囚われてしまいます。

例えば、あの時の失敗を思い出し、恥の感情で胸が締め付けられるような感覚を得る。
例えば、あの時の成功を思い出し、それと現在を比較し、がっかりする。

そんな囚われは、大した意味を持ちません。

あの時の失敗を分析し、それを繰り返さないように活かすこと。
あの時の成功を分析し、それを再現可能にすること。

それらが、私がすべきことであり、**SelfOrWorld**はその実践を助けてくれます。

### どうやって
日常に没頭している間は、その行為ごとに反省することは好ましくありません。

ただ過去を振り返らず、その時々で必要なことをただ為していく。

それに集中していればよいのです。

しかし、未来を一度生きた私にとって、その時刻に行うべきことは決まっています。
(より大事な割り込みが無い限り。)

それを着実にこなしていきましょう。

そしてその日を終了する前の少しの時間で、過去を振り返り、学びを得ましょう。

#### ReLiving
**SelfOrWorld**は、その日一日を追体験し、その時々での学びを記録することが出来ます。

一日の始まりから私が為したことを順に追体験し、それを経て学んだことを記録します。

その学びは、「大事なこと」を鮮明にすること、上手く為すことを助けます。

過去から学ぶにつれて、大事なことを為す仕方は、上手くなってゆくことでしょう。

# Postscript: Self or,
「私」という言葉は、とてもユニークな言葉です。

それは、言葉を発する話者が誰なのかによって、意味を変えます。

私の「私」は、あなたの「私」ではありません。

でもそんな「私」のために、このアプリケーションはあります。

## 開発状況・技術スタック

### フロントエンド
- **フレームワーク**: React 19 + TypeScript
- **UIライブラリ**: Material-UI (MUI)
- **ビルドツール**: Vite
- **ルーティング**: React Router
- **可視化**: D3.js

### バックエンド (実装済み)
- **フレームワーク**: Python FastAPI
- **データベース**: Neo4j (グラフデータベース)
- **バリデーション**: Pydantic
- **API仕様**: OpenAPI (Swagger)

## クイックスタート

### 前提条件
- Node.js 18以上
- Python 3.11以上
- Docker & Docker Compose (推奨)

### Dockerを使用する場合（推奨）

```bash
# Docker Composeで全てのサービス（データベース、バックエンド、フロントエンド）を起動
docker-compose up -d

# または、ログを確認しながら起動
docker-compose up
```

アクセス:
- **フロントエンド**: http://localhost:5173
- **バックエンドAPI**: http://localhost:8000
- **APIドキュメント**: http://localhost:8000/docs
- **Neo4j Browser**: http://localhost:7474

```bash
# サービスの停止
docker-compose down

# ボリュームも削除して完全にクリーンアップ
docker-compose down -v
```

### 手動セットアップ

#### 前提条件
- Node.js 18以上がインストール済み
- Python 3.11以上がインストール済み
- Neo4j 5.0以上が起動中（ローカルまたはクラウド）

#### VSCode起動設定（推奨）

VSCodeの「実行とデバッグ」パネルから以下の設定が利用可能です：

**個別起動:**
- `Frontend (Vite Dev Server)` - フロントエンドのみ起動
- `Backend (FastAPI)` - バックエンドのみ起動（ローカルNeo4j）
- `Backend (FastAPI) - Neo4j Cloud` - バックエンドのみ起動（Neo4jクラウド）

**一括起動:**
- `Full Stack (Local Neo4j)` - フロントエンド + バックエンド（ローカルNeo4j）
- `Full Stack (Neo4j Cloud)` - フロントエンド + バックエンド（Neo4jクラウド）

**注意:** Neo4jクラウドを使用する場合は、[.vscode/launch.json](.vscode/launch.json:64-67) の以下の環境変数を編集してください：
- `NEO4J_URI`: クラウドインスタンスのURI（例: `neo4j+s://xxxxx.databases.neo4j.io`）
- `NEO4J_USER`: ユーザー名
- `NEO4J_PASSWORD`: パスワード

#### コマンドライン起動

詳細は各ディレクトリのREADMEを参照:
- [フロントエンド](./frontend/README.md)
- [バックエンド](./backend/README.md)

## 実装済み機能

### WorldTree (価値観の記録と鮮明化)
- ✅ フロントエンド: D3.jsによるツリー可視化
- ✅ バックエンド: Neo4jグラフDBによる階層構造管理
- ✅ API: CRUD操作、ノード移動、並び替え

### Compact (未来の圧縮体験)
- ✅ フロントエンド: 週間時間配分の可視化（モック）

### Immersion (明日の準備)
- ✅ フロントエンド: 日次タイムライン（モック）

### ReLiving (過去からの学び)
- ✅ フロントエンド: 一日の追体験と学び記録（モック）
